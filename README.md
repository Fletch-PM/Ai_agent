# JARVIS AI Agent

JARVIS is a Streamlit-based personal AI assistant built with LangGraph. It
accepts typed or spoken questions, routes each request to the appropriate
agent workflow, and can respond with text and generated speech.

## What I built

- A Streamlit chat interface with conversation history.
- Microphone input through ElevenLabs speech-to-text.
- Automatic spoken responses through ElevenLabs text-to-speech.
- A LangGraph workflow with three routes:
  - **Orchestrator**: classifies the request and checks personal reference
    information.
  - **Researcher**: gathers web or weather information before answering.
  - **Author**: writes requested content and saves it as a Word document.
- Claude integration through LangChain Anthropic models.
- Retrieval-augmented generation (RAG) with Qdrant and FastEmbed.
- Local document ingestion from the `documents/` folder.
- Web search and live weather lookup using external APIs.
- An agent graph diagram generated by `draw_agent_graph.py`.

## Setup on Windows

1. Create and activate a virtual environment:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Install the dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Create a `.env` file in the project root and configure the services used by
   the application. The main settings are:

   ```text
   ANTHROPIC_API_KEY=
   ANTHROPIC_MODEL=claude-sonnet-4-6
   ANTHROPIC_HAIKU_MODEL=claude-haiku-4-5

   QDRANT_URL=
   QDRANT_API_KEY=
   QDRANT_COLLECTION_NAME=ai_agent

   ELEVENLABS_API_KEY=
   ELEVENLABS_VOICE_ID=
   ELEVENLABS_TTS_MODEL=eleven_multilingual_v2
   ELEVENLABS_STT_MODEL=scribe_v1
   ```

   Optional voice controls include `ELEVENLABS_SPEED`,
   `ELEVENLABS_STABILITY`, `ELEVENLABS_SIMILARITY`, and
   `ELEVENLABS_STYLE`. The application also supports optional LangSmith
   tracing variables.

   Never commit `.env` or share API keys. If a key has been exposed, revoke it
   and create a replacement.

## Run the assistant

Start the Streamlit application from the project root:

```powershell
streamlit run main.py
```

Then open the local URL displayed by Streamlit. Type a message in the chat
box, or use the microphone input when ElevenLabs credentials are configured.

Examples of supported requests:

- Ask general questions that require research.
- Ask for the current weather in a location.
- Ask questions about personal reference documents.
- Ask the assistant to write a paper or other long-form content.

Generated papers are saved as `.docx` files in `documents/`.

## Add documents to the knowledge base

Place `.txt`, `.md`, or `.markdown` files in `documents/`, then run:

```powershell
python -m app.tools.rag.ingest
```

Alternatively, specify another folder:

```powershell
python -m app.tools.rag.ingest path\to\documents
```

The ingestion process splits documents into parent and child chunks, creates
dense and sparse embeddings, and stores them in the configured Qdrant
collection.

## Generate the agent graph

To regenerate the workflow diagram:

```powershell
python draw_agent_graph.py
```

## Notes

- Claude is required for agent responses. Without `ANTHROPIC_API_KEY`, the
  application displays a configuration message instead of calling the model.
- Voice features are optional. Without `ELEVENLABS_API_KEY`, the text chat
  remains available but speech input and output are disabled.
- Qdrant is used for personal-document retrieval and must be reachable when
  the RAG components are initialized.
